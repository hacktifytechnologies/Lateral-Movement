# T1021.002 – SMB Admin Shares | Assessment

## MCQ 1
`C$`, `ADMIN$`, and `IPC$` are Windows default administrative shares. They require:
A) Any authenticated user  B) Anonymous access
C) Local administrator credentials on the target system  ✅  D) Domain admin credentials only

## MCQ 2
PsExec uses which admin share to deploy its service binary on the remote host?
A) C$  B) IPC$  C) ADMIN$  ✅  D) SYSVOL

## MCQ 3
`net use Z: \\host\C$ /user:domain\user pass` — what does `/user:` specify?
A) The local user running the command  B) The credentials used to authenticate to the remote SMB share  ✅
C) The share owner  D) The encryption key

## Fill 1
`net view \\host /all` flag that reveals hidden shares (ending in `$`):
**Answer:** `/all`

## Fill 2
Event ID in Windows Security log that records network logon via SMB:
**Answer:** `4624` (with Logon Type 3 – Network)
