## MCQ 1
`sshpass -p 'password' ssh user@host "cmd"` is used in lateral movement scripts because:
A) It encrypts the connection stronger than regular SSH
B) It allows non-interactive password authentication, enabling scripted lateral movement across multiple hosts  ✅
C) It bypasses SSH host key checking automatically
D) It runs the command with root privileges

## MCQ 2
SSH `ProxyJump` (`-J`) is used in red team operations to:
A) Speed up SSH connections
B) Route SSH connections through intermediate hosts to reach otherwise unreachable internal systems  ✅
C) Encrypt the jump host credentials
D) Bypass SSH key authentication

## MCQ 3
`ssh-copy-id` installs a public key to a remote host's:
A) `/etc/ssh/authorized_keys`  B) `~/.ssh/known_hosts`
C) `~/.ssh/authorized_keys` of the target user  ✅  D) `/root/.ssh/id_rsa`

## Fill 1
SSH flag to skip interactive host key verification (useful for scripted lateral movement):
**Answer:** `-o StrictHostKeyChecking=no`

## Fill 2
SSH config directive to define a jump host for a target:
**Answer:** `ProxyJump <jump-host>`
