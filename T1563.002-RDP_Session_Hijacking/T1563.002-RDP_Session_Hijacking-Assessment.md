# T1563.002 – RDP Session Hijacking | Assessment

## MCQ 1
`tscon.exe <SessionID> /dest:console` works without the victim's password because:
A) RDP sessions don't use passwords  B) tscon.exe as SYSTEM bypasses Terminal Services authentication and directly switches session context  ✅
C) The session password is stored in cleartext  D) It requires a registry modification first

## MCQ 2
`qwinsta` / `query session` is used in RDP hijacking to:
A) Enumerate domain accounts  B) List all active and disconnected RDP/console sessions and their IDs  ✅
C) Check firewall rules for RDP  D) Verify RDP certificates

## MCQ 3
RDP session hijacking is particularly stealthy because:
A) It creates no event logs  B) The hijacked session inherits the victim's existing authentication token — no new logon event is generated for the attacker  ✅
C) tscon.exe is not monitored  D) RDP traffic is encrypted

## Fill 1
Command to list all Windows terminal server sessions:
**Answer:** `qwinsta` (or `query session`)

## Fill 2
tscon.exe requires this privilege level to hijack another user's session:
**Answer:** `SYSTEM` (NT AUTHORITY\SYSTEM)
