# T1021.004 – SSH Key Hijacking | Assessment

## MCQ 1
An attacker prioritizes stealing SSH private keys because:
A) Private keys are faster to use than passwords
B) A stolen private key allows persistent passwordless access to all hosts that trust the corresponding public key  ✅
C) SSH keys bypass firewall rules
D) Private keys contain the target's password hash

## MCQ 2
`~/.ssh/known_hosts` is valuable for lateral movement planning because:
A) It contains stored passwords  B) It lists hosts the user has previously connected to, revealing the network topology  ✅
C) It stores SSH private keys  D) It contains login credentials

## MCQ 3
auditd rule to detect unauthorized reads of SSH private keys:
A) `-w /etc/ssh -p rx -k ssh_access`
B) `-w /home -p r -k home_read`
C) `-a always,exit -F arch=b64 -S open -F path=/home/user/.ssh/id_rsa -k ssh_key_read`  ✅
D) `-w /var/log/auth.log -p rw -k ssh_log`

## Fill 1
SSH flag to specify a private key file for authentication:
**Answer:** `-i /path/to/key`

## Fill 2
File in `~/.ssh/` that lists hosts a user has previously connected to (with their fingerprints):
**Answer:** `known_hosts`
