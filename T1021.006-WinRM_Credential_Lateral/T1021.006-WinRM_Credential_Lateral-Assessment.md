## MCQ 2

A) An encrypted string stored permanently  B) A SecureString object for use in PSCredential (kept in protected memory)  ✅
C) A Base64-encoded string  D) A NTLM hash

## MCQ 3
Which PowerShell command searches for password strings in files recursively?
A) `Find-Password -Path C:\`  B) `Get-ChildItem -Recurse | Select-String -Pattern "password"`  ✅
C) `Search-ADAccount`  D) `Get-Credential`

## Fill 1
`New-Object PSCredential($username, $secureString)` creates:
**Answer:** A PSCredential object used for authentication in remoting cmdlets

## Fill 2
PowerShell cmdlet to check what privileges a credential has on the local system:
**Answer:** `whoami /priv` (via Invoke-Command) or `net localgroup Administrators`
