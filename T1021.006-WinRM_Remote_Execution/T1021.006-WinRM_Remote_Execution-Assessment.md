## MCQ 3
`evil-winrm` is a red-team tool that communicates via:
A) SMB port 445  B) RDP port 3389  C) WinRM (port 5985/5986) with a full interactive PowerShell shell  ✅  D) RPC port 135

## Fill 1
PowerShell cmdlet to start an interactive remote shell session:
**Answer:** `Enter-PSSession -ComputerName <host>`

## Fill 2
Command to enable WinRM on a Windows host (run as admin):
**Answer:** `Enable-PSRemoting -Force`
