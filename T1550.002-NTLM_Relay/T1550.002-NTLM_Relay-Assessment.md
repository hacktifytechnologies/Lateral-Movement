## MCQ 2
Responder (Python) poisons which protocols to capture NTLM hashes?
A) DNS and HTTP only  B) LLMNR, NBT-NS, and MDNS  ✅  C) Kerberos and LDAP  D) SMTP and POP3

## MCQ 3
`ntlmrelayx.py -t smb://target --no-http-server` relays captured authentication to:
A) A web server  B) The attacker's own system  C) The specified SMB target using the victim's credentials  ✅  D) An LDAP server

## Fill 1
PowerShell command to enforce SMB signing (mitigation for NTLM relay):
**Answer:** `Set-SmbServerConfiguration -RequireSecuritySignature $true`

## Fill 2
Registry path to disable LLMNR (one of Responder's poisoning protocols):
**Answer:** `HKLM\SOFTWARE\Policies\Microsoft\Windows NT\DNSClient\EnableMulticast = 0`
